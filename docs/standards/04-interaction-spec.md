# 04 · 页面交互规范（Interaction Spec）

适用范围：所有用户可见的页面行为、路由与反馈机制。目标是让全站交互**可预期**：同一意图永远触发同一模式。

## 1. 导航与布局

- 全站骨架由 `AppShell` 提供：左侧图标栏（Rail）+ 内容区 + 右侧任务抽屉（TaskDrawer）；项目空间内额外渲染中间视图导航面板（ProjectPanel），项目列表统一由 `/projects` 页承担。
- **Rail** 只放一级入口（工作台/项目/用户/设置），激活项高亮 `--color-rail-fg-strong` 底。
- **层级导航**：`Breadcrumbs` 展示 项目 → 视图；进入项目后视图切换（看板/列表/表格/日历/时间轴/统计/设置）不离开项目上下文。
- **全局搜索**：头部搜索框（聚焦即出面板），支持项目/任务直达。
- 浏览器前进/后退必须可用：视图与选中态同步到 URL（searchParams），刷新不丢状态。

## 2. 页面三态（每个数据页面必须齐备）

| 状态 | 要求 |
| --- | --- |
| 加载态 | 首屏用骨架占位；切换视图瞬时（<200ms）可省略 |
| 空态 | 说明文案 + **引导动作**（如"创建第一个项目"按钮），配 `--color-text-muted` 弱化图标 |
| 错误态 | 领域错误转成人话（"任务已被他人修改，请刷新"），提供重试；不展示堆栈 |

## 3. 表单与输入

- **创建**：主入口按钮打开弹层/抽屉；快捷创建（列表内联输入）必须 **Enter 确认、Esc 取消**，失焦不静默提交。
- **编辑**：就地编辑（点击文本变输入框）或抽屉表单；保存成功用 Toast 轻提示，失败保留用户输入并标错误字段。
- **必填/校验**：前端即校验（Zod schema 复用 `~/models`），错误信息在字段下方红字（`--color-danger`），聚焦第一个错误字段。
- 危险操作（删除项目/批量删除）必须走 `ConfirmDialog` 二次确认，确认按钮用 danger 样式且**非默认焦点**。
- 批量操作：多选后底部浮出批量操作栏（`db-actionbar`），含已选计数与"取消选择"。

## 4. 反馈机制

| 场景 | 方式 | 现有组件 |
| --- | --- | --- |
| 操作成功 | Toast（深色反色浮层，2.5s 自动消失） | `ui/Toast` |
| 操作失败 | Toast error 变体（`--color-on-danger` 前景）或表单内联错误 | `ui/Toast` |
| 不可逆确认 | 模态对话框，说明后果 + 输入项名称确认（项目级删除） | `ui/ConfirmDialog` |
| 轻量选择 | 弹出面板，点击外部/Esc 关闭 | `ui/Popover` |

- 同类 Toast 连续触发时合并，不叠一列。
- 删除默认进回收站（软删除，`deletedAt`），回收站可恢复/彻底删除；彻底删除才用 ConfirmDialog。

## 5. 键盘与焦点

- 全局：`/` 聚焦全局搜索；`Esc` 逐层关闭（Dialog → Drawer → Popover → 搜索面板）。
- 弹层打开时焦点移入，关闭时还给触发元素；Tab 不跑出 Dialog（焦点圈定）。
- 列表/表格支持 `↑ ↓` 移动选中、`Enter` 打开详情；看板卡片可聚焦。
- 所有可点目标命中区 ≥ 24px，焦点环样式统一走全局 `:focus-visible`。

## 6. 拖拽与排序

- 看板卡片、列表行拖拽用 `@dnd-kit`：拖起 `--shadow-lg` + 半透明，目标位显示 `--color-primary` 描边占位。
- 落点即时乐观更新，持久化用 fractional index；失败回滚原位并 Toast 提示。
- 拖拽过程禁用文本选中与页面滚动干扰（`touch-action` 处理）。

## 7. 动效

- 时长：微交互（hover、按下）`--motion-fast`(100ms)；显隐过渡（抽屉、弹层）`--transition`(150ms)；不新增 > 250ms 的动效。
- 一律 ease；位移 ≤ 8px（Toast 滑入、抽屉位移除外）；**禁止**弹跳、旋转、无限循环动画（loading 转圈除外）。
- 必须尊重 `prefers-reduced-motion: reduce`（全局已统一降级为 0.01ms，新动画不得绕过）。

## 8. 文案（i18n）

- 所有用户可见文案走 `~/locales/zh-CN.ts` + `en.ts`（`~/lib/i18n.ts` 取用），**禁止在组件里写死中文/英文字符串**（数据驱动的动态内容除外）。
- 语气：简洁、动词开头（"创建项目"、"删除成员"）；错误文案说明原因与出路，不指责用户。
- 中英双语键必须同步新增；漏键是缺陷。
- 数字与日期展示用 `~/lib/date.ts` 统一格式（相对时间/本地化日期），不自造格式。

## 9. 性能感知

- 任何用户操作 **100ms 内必须有视觉响应**（按钮态、乐观更新或 loading 指示）。
- 路由切换预取数据（Remix `Link` 预取）；超过 1s 的不可拆操作需进度指示或可取消。
