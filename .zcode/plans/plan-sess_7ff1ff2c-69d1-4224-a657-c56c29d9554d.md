# 功能精简 + Worktile 能力扩展计划

## 一、删除四个功能（彻底删除：页面 + 服务 + 数据表 + 调用点）

**删除文件**：
- 路由：`_app.notifications.tsx`、`_app.trash.tsx`、`_app.admin.users.tsx`、`_app.admin.audit.tsx`
- 服务/模型：`notification.service.ts`、`models/notification.ts`、`audit.service.ts`、`models/auditLog.ts`、`user.service.ts`、`mention.service.ts`

**调用点清理**：
- `task.service.ts`：4 处 notify + 4 处 audit 写入删行；`comment.service.ts`：3 处 notify + 1 处 audit + mentions 落库删行
- `TaskDrawer`：移除「动态」tab（保留评论）；工作台 `_app._index.tsx`：移除「最近动态」卡片
- `AppRail`：删通知（含未读数 liveQuery）/回收站/admin 分组入口，只留 工作台/项目 + 底部设置/头像（UserCard 身份切换保留，指派演示需要）
- `db.ts` version(3) 删 notifications、auditLogs 两表；`backup.service.ts` 同步去字段并兼容旧备份导入（忽略已删表）；`app/index.ts` 出口清理；`roles.ts` 移除 `user:manage` 权限
- 测试：删 `audit.service.test.ts`、`user.service.test.ts`、`comment.test.ts`；`task.update/task.permission/workbench/task.service` 测试去掉通知与审计断言
- locales 清理 notif*/用户管理/审计相关 key；删除确认文案改为「软删除 + toast 撤销 + 30 天自动清理」

**保留**：`trash.service.ts` 的软删除体系（deleteTask/deleteProject + undo 撤销 + purgeExpired 自动清理）— 它是任务/项目删除流程的内部机制，仅回收站页面消失；软删过滤（GlobalSearch、看板等）不动。

## 二、数据模型扩展（db version(4) 一次性增表）

新表：`labels`（项目级彩色标签）、`taskLinks`（blocks/relates 关联）、`milestones`（里程碑）、`automations`（规则）、`projectTemplates`、`taskTemplates`。
Task 模型新增字段：`startDate`（甘特跨度）、`customValues`（自定义字段值）、`recurrence`（周期规则，可空）；启用已有 `labels` 字段。

## 三、新视图（项目 Tab：看板/列表/表格/日历/时间线/统计 + 设置）

1. **表格视图**：自定义字段（文本/数字/日期/单选）定义 + 列显隐配置 + 行内单元格编辑，复用列表视图的 db-* 组件模式与虚拟滚动
2. **日历视图**：月网格按 dueDate 排布，拖拽改期（HTML5 DnD），点日期快捷创建，今日/逾期高亮
3. **甘特/时间线**：startDate→dueDate 横向条带，日/周/月缩放，依赖关系箭头（SVG），里程碑菱形锚点

## 四、任务能力

1. **标签系统**：项目设置里标签 CRUD（名称+颜色），卡片/列表/表格/抽屉显示标签 chip，列表与表格按标签筛选
2. **任务关联/依赖**：TaskDrawer「关联」字段行 + 搜索选择器；阻塞/被阻塞/关联分组展示与跳转；成环校验；被阻塞任务完成时警告；甘特图箭头联动
3. **重复任务/模板**：详情抽屉设置周期（每日/每周/每月），完成时自动生成下一期；任务模板库（保存当前任务为模板、从模板创建）

## 五、项目能力

1. **里程碑**：项目设置管理（标题/日期/完成态），时间线菱形标记 + 看板列头进度联动展示
2. **自动化规则**：项目设置「自动化」tab 维护 when-then 规则；触发器=任务创建/进入某列/完成时，动作=指派/设优先级/移到列/加标签；引擎挂在 task.service 流程后
3. **统计报表**：项目「统计」tab，纯 SVG 零依赖图表——燃尽图、成员负载、完成趋势、状态/优先级分布
4. **项目模板**：内置模板（研发迭代/营销活动等）+ 项目「另存为模板」（存列/标签/字段/任务模板）；/projects 新建流程可选模板起步

## 实施顺序（每阶段 typecheck+tests+build，浏览器走查，分阶段 commit）

1. P0 删除四功能 + 全部调用点清理 + db v3 + 测试修复
2. P1 db v4 增表 + 标签系统全链路
3. P2 表格视图（自定义字段）
4. P3 日历视图
5. P4 任务关联/依赖 + 甘特时间线
6. P5 里程碑
7. P6 重复任务 + 任务模板
8. P7 项目模板
9. P8 自动化规则
10. P9 统计报表 → 最终浏览器全面走查 + push 部署 GitHub Pages
